In Part 4, my `UPDATE Student SET dept_id = 2 WHERE matric_no = '12134';` failed in MySQL Workbench with Error Code 1175: "You are using safe update mode and you tried to update a table without a WHERE that uses a KEY column." MySQL refuses because safe update mode (`SQL_SAFE_UPDATES`) only allows `UPDATE` and `DELETE` statements whose `WHERE` clause uses a key column (primary key or an indexed column). This stops a statement from accidentally changing or deleting many rows at once. My `WHERE` used `matric_no`, which is not a key column, so MySQL could not guarantee that only one row would be affected. I fixed it by temporarily turning safe mode off with `SET SQL_SAFE_UPDATES = 0;`, running the update, and turning it back on with `SET SQL_SAFE_UPDATES = 1;`. Another fix would have been to filter on the primary key instead, for example `WHERE student_id = 1`, which works with safe mode left on. I could also have added a `UNIQUE` index on `matric_no`, so MySQL accepts it as a key column in the `WHERE` clause.
